# Fakturetako datuak (zaharkituta)

Lehen bertsioan 189.536, 193.818 eta 197.703 albaranetatik prezioak eta erosketen historia atera ziren.
Albarán horiek ez daude eguneratuta, beraz:

- **Erosketen eta itzulketen historia kendu da.**
- Erosketa-prezioak produktuetan daude baina **berretsi gabe** markatuta. Aldatu Ezarpenak → Produktuak atalean.
- Pack-tamainak erabiltzaileak emandakoak: San Miguel 20 cl eta 0,0 → 30, glutenik gabe → 24, latak → 24, botilak → 6, ura → 35.
